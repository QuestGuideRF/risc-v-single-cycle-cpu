# RISC-V Single Cycle CPU

Реализация однотактного процессора RISC-V RV32I на Verilog и Chisel. Проект включает полную реализацию ядра процессора с поддержкой базового набора инструкций RISC-V, систему памяти, периферийные устройства и тестовые бенчмарки.

## Описание

Этот проект представляет собой полнофункциональную реализацию однотактного процессора RISC-V, соответствующую спецификации RV32I. Процессор выполнен в архитектуре single-cycle, где каждая инструкция выполняется за один такт. Проект включает реализацию на двух языках описания аппаратуры: Verilog и Chisel (Scala), что позволяет использовать различные инструменты синтеза и симуляции.

## ✨ Особенности

- **Полная реализация RV32I**: Поддержка всех базовых инструкций RISC-V 32-битной архитектуры
- **Однотактное выполнение**: Каждая инструкция выполняется за один такт синхронизации
- **Модульная архитектура**: Разделение на блок управления (Control Path) и тракт данных (Data Path)
- **Двойная реализация**: Версии на Verilog и Chisel для максимальной гибкости
- **Периферийные устройства**: Встроенная поддержка GPIO для взаимодействия с внешними устройствами
- **Тестовые бенчмарки**: Полный набор тестов для проверки корректности работы всех инструкций
- **FPGA совместимость**: Готовые модули для развертывания на FPGA платформах (Arty A7-100T)
- **Logisim схема**: Визуальная схема процессора для образовательных целей

## 🚀 Быстрый старт

### Требования

- **Для Verilog**:
  - Симулятор Verilog (VCS, ModelSim, Icarus Verilog, Verilator)
  - Синтезатор для FPGA (Vivado, Quartus) - опционально

- **Для Chisel**:
  - Java JDK 8 или выше
  - Scala 2.13.12
  - Mill build tool
  - Chisel 6.2.0

### Сборка и запуск

#### Verilog версия

1. Перейдите в директорию с Verilog кодом:
```bash
cd verilog
```

2. Для симуляции используйте один из доступных тестовых бенчмарков:
```bash
# Пример с использованием VCS
vcs -full64 verilog/rtl/*.v verilog/lib/*.v verilog/sim/tb_core.sv -o simv
./simv
```

3. Для синтеза на FPGA используйте соответствующий синтезатор (Vivado/Quartus) с файлом `verilog/rtl/top.v` в качестве верхнего уровня.

#### Chisel версия

1. Перейдите в директорию Chisel:
```bash
cd chisel
```

2. Соберите проект с помощью Mill:
```bash
mill BA30XSystem
```

3. Для запуска тестов:
```bash
mill BA30XSystem.test
```

4. Для симуляции:
```bash
make sim
```

### Загрузка программы

Программы для процессора должны быть скомпилированы в формат `.mem` и размещены в `verilog/software/firmware.mem`. Пример программы на ассемблере находится в `verilog/software/firmware.S`.

## 🛠 Использование

### Архитектура процессора

Процессор состоит из следующих основных компонентов:

- **Core**: Ядро процессора, объединяющее блок управления и тракт данных
- **ControlPath**: Декодирует инструкции и генерирует управляющие сигналы
- **DataPath**: Выполняет операции над данными, содержит регистровый файл, ALU, генератор констант
- **Tile**: Системный уровень, включающий процессор, память программ (ROM), память данных (RAM) и GPIO

### Поддерживаемые инструкции

Процессор поддерживает полный набор инструкций RV32I:

- **Арифметические**: ADD, SUB, ADDI
- **Логические**: AND, OR, XOR, ANDI, ORI, XORI
- **Сдвиги**: SLL, SRL, SRA, SLLI, SRLI, SRAI
- **Сравнения**: SLT, SLTU, SLTI, SLTIU
- **Загрузка**: LW, LH, LB, LHU, LBU
- **Сохранение**: SW, SH, SB
- **Управление потоком**: BEQ, BNE, BLT, BGE, BLTU, BGEU, JAL, JALR
- **Константы**: LUI, AUIPC
- **Системные**: ECALL, EBREAK, CSR инструкции

### Программирование

Пример программы на ассемблере (`verilog/software/firmware.S`):

```assembly
# GPIO base address
li s0, 0x10010000

# delay amount
li s1, 1000000

# led status
li s2, 0x1

sw s2, 0(s0)

loop:
  li t0, 0
delay:
  addi t0, t0, 1
  blt t0, s1, delay

  # update LED state
  sw s2, 0(s0)

  # alternate the LED state
  li t0, 1
  sub s2, t0, s2

  j loop
```

Эта программа мигает светодиодами через GPIO.

### Тестирование

Запуск тестового бенчмарка для проверки всех инструкций:

```bash
cd verilog/sim
# Используйте ваш симулятор для запуска tb_core.sv
```

Тесты проверяют:
- Все R-тип инструкции (ADD, SUB, SLL, SLT, XOR, OR, AND, SRL, SRA)
- Все I-тип инструкции (ADDI, SLTI, XORI, ORI, ANDI, загрузки)
- Все S-тип инструкции (SW, SH, SB)
- Все U-тип инструкции (LUI, AUIPC)
- Все J-тип инструкции (JAL, JALR)
- Все B-тип инструкции (BEQ, BNE, BLT, BGE, BLTU, BGEU)

## 🧪 Технологии

- **Verilog**: Язык описания аппаратуры для RTL проектирования
- **Chisel**: Язык высокого уровня на базе Scala для генерации Verilog
- **SystemVerilog**: Для тестовых бенчмарков
- **Logisim Evolution**: Для визуального моделирования схемы
- **Mill**: Система сборки для Scala/Chisel проектов

## Производительность

Однотактная версия может достигать частоты синхронизации около 300 Гц на компьютере с процессором i7-6700K при симуляции. Для реального развертывания на FPGA частота будет зависеть от целевой платформы и настроек синтеза.
